Help

Quick reference for what everything on the dashboard means.

Request statuses

Not Ready
Sitting in the project's _Requests/ folder, but not marked ready yet. The scheduler won't pick it up. Use Edit to change what it asks for, or Mark Ready when it's good to go.
Ready
Flipped to READY and waiting for the scheduler to wake that project's session.
Processing
The project's session is currently awake and working through its queue. If several requests are Ready at once, they all show Processing together for the whole pass — Claude works through them one at a time within that same session, not all at once, but the dashboard shows the whole queue as "in progress" rather than singling out whichever one happens to be open right now.
Waiting Response
Claude got partway through a request and is stuck on something only Brad can answer (a decision, credentials, etc). It'll stay this way until Brad edits it and flips it back to Ready.

Project card

Active / Inactive
Whether this project is in the scheduler's rotation pool. Active projects get woken automatically when they have Ready requests; Inactive ones are skipped.
Files
Opens the project's detail page — its Description, CLAUDE.md, and any .claude/agents/ files.
Archive
Browse past requests that have already been processed, in _Requests/_Archive/.
Waiting Input
Flashes when a request is WAITING RESPONSE -- stuck on a question only you can answer. Opens a list of those requests; pick one, read the question, type your answer into the body, then Save & Mark Ready to flip it back to READY so the scheduler picks it up again.
Console
Peek at (or type into) the project's live Claude Code session, if one is running.
+ Request
Drop a new request straight into the project's _Requests/ folder, with an optional screenshot or file attached.
