    Generic project folder structure
    
          
    The standard shape every project under ~/projects/ should have. See _Instructions/ProjectSetup.md for the full convention ("Setup Project" as a trigger phrase).
    
          
    <project>/
├── CLAUDE.md              # agent-facing: scheduler wake/kill, gotchas, conventions
├── Description.md         # human-facing: short summary + Git repository section
├── .claude/
│   └── agents/
│       └── <slug>/
│           └── <slug>.md  # one subagent definition per folder
└── References/
    └── README.md          # site-specific docs Brad drops in by hand
    
        
    
      
    
    
    
  
    

  
    
    
    
      
    Fleet — server grid
    
      
    
        One row per server, one Y/N column per package, so you can scan
        down what runs where. Read-only until you hit Edit; then
        edit cells in place and Save (or Cancel). Saved to
        Supabase when reachable, otherwise to
        state/ecosystem.json. The fuller form is on the
        Fleet tab. (This is "Ecosystem 2" — a spreadsheet-style
        alternative to the diagram on the Ecosystem tab, kept side
        by side for now.)
      
    
      
    
      
    
        
    
      
    
      
    
        Click any cell to edit it; click a Y/N cell to toggle. The
        Other and Apps columns are derived (from the
        free-text Software field and the App rows on the Fleet tab)
        and aren't editable here. Renaming a server here won't move its
        apps across — do that on the Fleet tab.
