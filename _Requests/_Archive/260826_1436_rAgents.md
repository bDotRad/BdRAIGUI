## What was done

Brad's Ecosystem tab (target fleet layout, added earlier the same day)
listed 4 agents for every project including BdRDev -- Project Manager,
Web Dev Export, Supabase SQL Expert, Doc Updater -- but the panel's own
note admitted none of them existed yet for BdRDev. This request asked
why, and to add real, generic (cross-project-reusable) agent
definitions if BdRDev is actually meant to use them.

Created all 4 under `BdRDev/.claude/agents/<slug>/<slug>.md` (the
established `list_agent_files()`-discoverable shape from
`_Instructions/ProjectSetup.md`):

- `project-manager` -- `_Requests/` triage/housekeeping entry point,
  delegates to the other three.
- `web-dev-expert` -- application-code changes (frontend/backend).
- `supabase-sql-expert` -- schema/migrations/SQL, respecting the
  "write SQL out for a human to run" hand-off convention where a
  project uses it.
- `doc-updater` -- keeps `CLAUDE.md`/`Description.md`/README/changelog
  in sync with reality.

Unlike PlanBdRad's agents (which are written specifically for that
project's domain), these four are written generically -- "this
project" throughout, no BdRDev-specific paths or domain baked in -- so
the same 4 files can be copied as-is into any other project's
`.claude/agents/` as a starting set, per Brad's "used across all
projects" ask. `_Instructions/ProjectSetup.md` was updated to point at
this set as the copyable generic template, alongside PlanBdRad as the
worked example for a project with real domain-specific agents.

Also fixed, while in the same section: the Ecosystem diagram had "Web
Dev Export" (typo for "Web Dev Expert") in all 6 project rows, and its
"not yet real" note was updated to reflect that BdRDev now has all 4
agents for real. Dashboard restarted (`kill -9` on `dashboard.py`,
systemd relaunched it) and the new text verified live via `curl`.

Not touched: BdRAMAssist/PlanBdRad/BdRBirdDetector/BdRIS/BdRDungeon's
own agent sets -- the note already correctly describes their state
(BdRAMAssist has 1 of 4; PlanBdRad/BdRBirdDetector have real agents
under different names; BdRIS/BdRDungeon don't exist as projects yet)
and nothing in this request asked for those to change.

Committed and pushed.
