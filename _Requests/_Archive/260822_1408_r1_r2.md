# r1 — logo square + bigger, r2 — activity log timestamp wrong

## r1: logo square and bigger

**Asked:** make the logo square and bigger.

**Found:** `#site-logo` in `app/templates/index.html` was 44x44px with
`border-radius: 50%` (a circle). The source image
(`app/static/rat-logo.png`) is 1312x816 — not square — and with no
`object-fit` set, forcing it into a 44x44 box was stretching/distorting it.

**Done:** bumped `#site-logo` to 84x84px, set `border-radius: 0` (square),
and added `object-fit: cover` so the non-square source crops cleanly
instead of stretching.

**Outcome:** verified via Flask's test client (index renders with
`width: 84px` present, `/static/rat-logo.png` still 200). Needs
`sudo systemctl restart bdraigui-dashboard` to pick it up — no passwordless
sudo here, left for Brad.

## r2: activity log timestamp wrong (showing 2300, actually 1300)

**Asked:** activity log timestamps look wrong — showed 2300 when it was
actually around 1300.

**Found:** `app/common.py` stores event times correctly as UTC ISO8601
(`datetime.now(timezone.utc).isoformat()`, e.g.
`2026-08-22T13:58:05+00:00`) — confirmed against the server clock (`date`
shows UTC, and it lines up with when r2 was actually created). The bug was
client-side: `renderLog()` in `index.html` did
`new Date(e.time).toLocaleTimeString([], {hour:'2-digit', minute:'2-digit'})`
with no `timeZone` option, which converts to whatever timezone *the
viewing device* is set to. On a device with the wrong timezone configured
(e.g. viewing over Tailscale from a phone/tablet), that produces exactly
this kind of multi-hour offset even though the underlying data is correct.

**Done:** added `timeZone: 'UTC'` to the `toLocaleTimeString` call, so the
log always displays the server's own clock rather than trusting the
viewing device's timezone setting — which is what actually matched Brad's
real wall-clock time here.

**Outcome:** verified via Flask's test client (`timeZone` present in
rendered page). Same restart caveat as above — needs
`sudo systemctl restart bdraigui-dashboard`, left for Brad.
